# Health Data Python Teaching

This repository provides simple Python examples for health-related and biological data preprocessing, visualization, and basic statistical analysis.

It is designed for beginners who are learning how to organize experimental data, clean tables, calculate basic statistics, and generate simple plots.

## Main topics

- Data preprocessing
- Survival curve data organization
- Body weight statistics
- Infection experiment data analysis
- Basic visualization with Python
- Reproducible teaching examples

## Background

This project is related to biological and health data analysis. The examples are inspired by experimental workflows such as survival rate recording, body weight measurement, infection experiment data organization, and basic statistical plotting.

The repository is also intended to support teaching in health big data and introductory Python courses.

## Files

- `example_data.csv`: example dataset for survival and body weight analysis
- `survival_analysis.py`: simple Python script for loading data, calculating survival rate, and plotting results
